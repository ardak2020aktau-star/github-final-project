All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute
1. Open an issue to describe a bug or proposed improvement.
2. Fork the repository and create a focused branch.
3. Make your changes and verify the calculator with sample inputs.
4. Commit your changes with a clear message and open a pull request.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). Contributions are made under the Apache License 2.0.
